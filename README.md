# MarkovBot — Telegram-бот для генерации текста

Курсовой проект по дисциплине «Основы программирования».
Студент: Комаревцев М.А., группа 253-325.

Telegram-бот, который запоминает сообщения чата в локальной базе данных и
отвечает сгенерированными фразами на основе цепей Маркова. Работает в
личных диалогах и групповых чатах (в т.ч. с темами).

## Возможности

- Генерация текста через марковские цепи переменного порядка (markovify).
- Контекстный поиск по корпусу с морфологической лемматизацией (pymorphy3)
  и взвешиванием TF-IDF.
- Инлайн-панель управления (`/panel`) с настройкой:
  - шанса ответа, медиа, демотиватора, мутации;
  - уровня «разумности» (от чистого Маркова до точных копий из корпуса);
  - уровня контекстной зависимости.
- Команды генерации (`v g`, `v g w`, `v g l`, `v g <число>`,
  `v g d`, `v g p`).
- Команды управления (`v c`, `v тихо`, `v говори`, `v set`, `v пинг`).
- Привязка бота к одной теме супергруппы (`v сиди здесь` / `v уходи`).
- Демотиваторы из присланных фотографий (Pillow).
- Хранение данных в SQLite (3 таблицы, индекс по user_id).

## Требования

- Python 3.10 или новее.
- Аккаунт Telegram, бот, зарегистрированный у [@BotFather](https://t.me/BotFather).
- **Доступ к Telegram API.** В РФ нужен либо VPN, либо локальный SOCKS5/HTTP
  прокси на машине запуска. Без них бот не сможет подключиться к
  `api.telegram.org` и упадёт с `ConnectTimeout`.

### Какие домены нужно проксировать

Если используется не VPN-туннель, а локальный прокси с правилами роутинга:
| Домен | Назначение |
|---|---|
| `api.telegram.org` | основной API бота |
| `core.telegram.org` | техническая документация (опционально) |
| `cdn-telegram.org`, `cdn1.cdn-telegram.org`, ... | CDN для медиафайлов |

Если короче — проксируйте всю категорию `geosite:telegram` (есть в v2rayN,
Nekoray, sing-box и Hiddify).

## Установка

### Вариант 1 — готовый бинарник из Releases

На странице [Releases](../../releases) лежат сборки для всех платформ:

| Платформа | Файл | Что делать |
|---|---|---|
| Windows | `MarkovBot-windows.exe` | Двойной клик. Если SmartScreen ругается «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае» |
| Linux   | `MarkovBot-linux`       | `chmod +x MarkovBot-linux && ./MarkovBot-linux` |
| macOS   | `MarkovBot-macos`       | `chmod +x MarkovBot-macos`, затем правый клик в Finder → «Открыть» → подтвердить (Gatekeeper) |

Подробнее про macOS Gatekeeper: при первой попытке запуска система покажет
«Не удаётся открыть, потому что разработчик не подтверждён». Это нормально
для неподписанных бинарников. Альтернативное решение в терминале:

```bash
xattr -d com.apple.quarantine MarkovBot-macos
./MarkovBot-macos
```

После запуска (на любой ОС):

1. **Включите VPN или локальный прокси** (см. раздел «Требования»).
2. При первом запуске визард предложит ввести токен бота от @BotFather,
   username бота, ваш Telegram user_id, адрес прокси.
3. Эти параметры сохранятся в `config.ini` рядом с бинарником.
4. База `bot.db` создастся автоматически и наполнится стартовым корпусом
   (~28 000 фраз — это занимает 5–10 секунд при первом запуске).
5. Бот стартует и начнёт работать.

При последующих запусках визард не появляется — параметры берутся из
существующего `config.ini`.

**Замечание про Windows Defender / антивирусы.** PyInstaller-сборки иногда
помечаются как «потенциально опасные» (false positive из-за PE-загрузчика).
Если такое произошло — добавьте бинарник в исключения антивируса.

## Конфигурация

Все настройки лежат в **`config.ini`** (рядом с бинарником или с
`bot.py`, если запуск из исходников). Файл `config.py` — это код,
который сам читает `config.ini` при старте; править его не нужно.

### Если запускаешь готовый бинарник из Releases

Просто запусти его в первый раз. Лаунчер откроет интерактивный мастер,
который попросит ввести токен, username, OWNER_ID и адрес прокси, и
сам сохранит всё в `config.ini` рядом. Все последующие запуски будут
читать этот файл без вопросов.

### Если запускаешь из исходников (`python bot.py`)

Создай рядом с `bot.py` файл `config.ini` со следующим содержимым:

```ini
[telegram]
token    = 1234567890:AAFgVp-JT0F...
username = bestInfo253bot
owner_id = 480547218

[proxy]
url      = socks5://127.0.0.1:10808

[logging]
verbose  = false
```

| Параметр | Что это |
|---|---|
| `token` | Токен бота от @BotFather (см. ниже) |
| `username` | Username бота без `@` |
| `owner_id` | Твой Telegram user_id, получить у @userinfobot. `0` = «нет владельца, только создатели чатов» |
| `url` | SOCKS5 / HTTP прокси, пусто — без прокси |
| `verbose` | `true` — расширенные логи с HTTP-трафиком и traceback'ами |

Все эти параметры также можно переопределить **переменными окружения**
с теми же именами в верхнем регистре (`TELEGRAM_TOKEN`, `BOT_USERNAME`,
`OWNER_ID`, `PROXY_URL`). Это удобно, например, в Docker / CI.

### Как получить TELEGRAM_TOKEN

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Команда `/newbot` → введите имя и username бота.
3. BotFather пришлёт токен формата `1234567890:AAFgVp-JT0F...`.
4. **ВАЖНО**: в `Bot Settings → Group Privacy` нажмите `Turn off`.
   Иначе бот не сможет читать обычные сообщения в группах.
5. Если бот уже добавлен в группу — удалите и добавьте заново, иначе
   изменение Privacy не применится.

## Первый запуск

```bash
python seed_corpus.py phrases_telegram.csv     # импорт стартового корпуса
python bot.py                                   # запуск бота
```

При старте увидите:

```
INFO - Предсборка модели Маркова (28725 сообщений)...
INFO - Прогрев кэшей: 28725 сообщений, 37889 лемм, 37535 слов за 0.6с
INFO - Модель и кэши готовы.
INFO - Используется прокси: socks5://127.0.0.1:10808
INFO - Бот запущен
```

Дальше можно открыть Telegram, найти своего бота и написать `/start`.

## Команды бота

### Генерация (доступно всем)

| Команда | Что делает |
|---|---|
| `v g` | сгенерировать текст |
| `v g <начало>` | текст с заданным началом |
| `v g <число>` | текст из N слов (1–250) |
| `v g l` | длинный текст (несколько предложений) |
| `v g w` | случайное слово из корпуса |
| `v g w <число>` | слово длиной N букв |
| `v g p` | опрос из сгенерированных вариантов |
| `v g d` | демотиватор (ответом на фото) |

### Управление (только владелец и создатель чата)

| Команда | Что делает |
|---|---|
| `v c` или `/panel` | инлайн-панель настроек |
| `v тихо [минуты]` | замутить бота на N минут |
| `v говори` | снять мут |
| `v set <ключ> <значение>` | изменить настройку |
| `v сиди здесь` | привязать к текущей теме |
| `v уходи` | снять привязку |
| `v где сижу` | список разрешённых тем |
| `/reset` | удалить свои сообщения из корпуса |
| `v пинг` | проверка, что бот жив |

### Стандартные slash-команды

`/start`, `/help`, `/panel`, `/reset`, `/demotivator`.

```
└── requirements.txt
```

## Технологии

- Python 3.10+
- `python-telegram-bot` 21+ — обёртка над Telegram Bot API
- `markovify` — построение цепей Маркова
- `pymorphy3` — морфологический анализ русского языка
- `Pillow` — рисование демотиваторов
- `httpx[socks]` + `socksio` — SOCKS5-прокси
- `sqlite3` (стандартная библиотека) — хранилище

## Известные ограничения

- Бот не работает без VPN/прокси с российских IP — у Telegram API ограничен
  доступ из РФ на уровне провайдера.
- Privacy Mode у бота должен быть **выключен** через BotFather, иначе бот
  не видит обычные сообщения в групповых чатах.
- При очень малом корпусе (<200 сообщений) генерация будет повторяться;
  для нормальной работы импортируйте `phrases_telegram.csv` или дайте
  боту накопить корпус.
